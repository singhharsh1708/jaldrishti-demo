# JalDrishti demo

Street-level urban flood nowcasting prototype for Chennai. Smart India Hackathon 2026, problem statement SIH26085 (Urban Flood Nowcasting System, MoES / NCMRWF).

- Live demo: https://singhharsh1708.github.io/jaldrishti-demo/
- Demo video: [jaldrishti_demo.mp4](jaldrishti_demo.mp4)

This repository holds only the built demo site and video. It is a prototype on test data:

- Flood rain is a synthetic, spatially uniform storm.
- Hydraulic parameters are uncalibrated.
- Silted and inferred drains come from an identical-twin test, not field findings.
- Streets are modelled as 1D channels along surveyed drains, not a 2D grid.
- The radar demo uses Mumbai because the Chennai radar was offline.

The method, data sources and caveats are on the demo's Method and data page.
